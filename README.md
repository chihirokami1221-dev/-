# 成長OS (成長・市場価値ステップアップアプリ)

日々の日記・ロードマップ・実績の積み上げから、市場価値スコア/ステージを算出する個人の成長管理アプリ。本業・副業・音楽の3領域を管理する。

**このアプリはログイン機能がなく、1人用(ローカル実行)です。** 動かすと自分のPC内だけにデータが保存されます。他の人と同じサーバーを共有するものではなく、それぞれが自分のPCでこのコード一式を動かして使う形を想定しています。

## セットアップ

Node.js 20以上が必要です。

```bash
npm install
npx prisma db push       # 初回のみ(DB作成)
npm run seed             # 初回のみ(カテゴリseed)
npm run dev
```

http://localhost:3000 を開く。

DBはSQLite(`prisma/dev.db`、Gitには含まれません)。内容を見る/編集する場合は `npx prisma studio`。

### AI機能(ローカル・無料)を使う場合

[Ollama](https://ollama.com)をインストールし、モデルを取得して起動しておく(課金なし・データは外部に送信されない)。

```bash
ollama pull qwen2.5:7b
ollama serve
```

使うモデルは `.env` の `OLLAMA_MODEL` で変更できる(PCスペックが厳しい場合は `qwen2.5:3b` など軽量モデルに変更)。Ollamaが起動していない間は、日記のAI分析はエラーメッセージを返す。CPU推論のため1回の分析に数十秒かかる。

## 主な機能

- 日記入力・履歴(カレンダー表示・キーワード検索)・AI分析・AIによる実績候補抽出(ローカルOllama連携)
- ロードマップ管理(計画ブロック・重点行動のCRUD)・ガントチャート表示
- 個別目標(ロードマップの重点行動から自動生成 / 手動追加の両方に対応。期限・優先度で整理)
- 実績データベース(成果・再現性・第三者評価・収益化フラグ・市場価値5軸との紐付け)
- 市場データ(求人情報の手動登録。市場需要軸・ギャップ分析に利用)
- メモ(タイトル一覧→タップで詳細)
- ダッシュボード(3領域の今週の進捗・市場価値スコア・ウィークリーToDo・おすすめタスク・今日のおすすめ本・今日の哲学者の一言)
- 市場価値ステージ(LEVEL1〜8)・5軸評価(根拠と不足証拠、計算式を表示)
- AIチャット(ローカルOllama連携)
- スマホのホーム画面に追加可能(PWA対応)

## 制約(今後の拡張ポイント)

- **AI機能はローカルモデル(Ollama)のみ**: 日記のAI分析・実績候補抽出・チャットはOllama経由のローカルLLMで行っている。市場価値のAI判定はまだルールベースのまま。クラウドAPI(Claude等)に切り替える場合は`src/lib/ollama.ts`を置き換える想定。
- **市場価値スコアはルールベース**: 登録した実績の件数・再現性・第三者評価・収益化フラグ、市場データとの一致から機械的に算出している(`src/lib/marketValue/score.ts`)。AIの主観評価は入っていない。
- **市場データは手動登録のみ**: 求人情報の自動取得(スクレイピング・有料API)は行っていない。
- **おすすめ本・哲学者の一言は固定の厳選リスト**: ハルシネーション防止のため、AIが即興生成せず、事前にWeb検索で実在確認した書籍・出典が確立した名言のみを掲載(`src/lib/bookRecommendations.ts`, `src/lib/philosopherQuotes.ts`)。日替わりで表示を切り替えるのみで、リアルタイムの市場調査ではない。
- **TimeTree/Notion連携は未実装**: 日記にカレンダー表示のみ。
